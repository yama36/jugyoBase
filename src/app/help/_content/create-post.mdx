<h2 id="create-post">授業実践を投稿する</h2>

ヘッダーの「**新規投稿**」、または事例一覧右上の「**新規投稿**」ボタンから投稿を作成できます。

<HelpMock variant="post-form" />

### 入力項目

必須は <strong className="text-red-600">＊</strong> マークの項目です。

- **タイトル**＊
- **カテゴリ**＊：授業 / 業務改善 / AI・ICT活用
- **学年**＊：1年・2年・3年・**共通** から選択（「共通」は学年横断の事例向け）
- **教科**＊：国語・社会・数学・理科・音楽・美術・保健体育・技術・家庭・英語・道徳・学活・総合・**共通** から選択
- **単元**：先に学年・教科を選ぶと、指導要領由来の候補が出てきます。**「候補から選ぶ」**と**「自由入力」**を切り替えられ、候補にない場合は自由入力で記入できます。マスタ上で学年または教科が「共通」になっている単元は、該当する組み合わせの候補にも表示されます。**カテゴリが授業以外の場合は任意**です。
- **内容項目**（任意）：単元の中の小トピックや、指導要領上の細目があれば
- **本文4項目**：カテゴリに応じてラベルが切り替わります（入力欄は共通）
  - 授業：めあて / 振り返り / 工夫した点 / 授業の流れ
  - 業務改善：課題・背景 / 効果・結果 / 試みたこと / 気をつける点
  - AI・ICT活用：活用場面 / よかった点・気をつけた点 / 使用したAI・ツール名 / 使ったプロンプト例
- **ハッシュタグ**：`#` は不要。スペース・カンマ・読点などで区切り（例：`協同学習 国語 振り返り`）
- **参考URL**（任意）：入力した URL は投稿詳細でリンクとして表示されます

### 下書きの自動保存

新規投稿画面では、フォームの入力内容が**自動で下書き保存**されます（ポリシー同意前でも保存されます）。別ページへ移動して `/posts/new` に戻っても、直前の入力を続きから再開できます。

### 添付ファイル

フォーム上部の「**ファイルを選択**」から添付できます。**保存前から**添付の登録ができ、PDF・画像・動画など**種類の違うファイルをまとめて複数選択**できます（種類はファイルから自動判定）。複数ファイルを選んだときは、件数に応じて順にアップロードされます。

| 種類 | 主な拡張子 | サイズ上限 |
| ---- | ---------- | ---------- |
| PDF | `.pdf` | 25 MB |
| スライド（PowerPoint） | `.pptx` `.ppt` | 25 MB |
| 画像 | `.jpg` `.jpeg` `.png` `.webp` `.gif` | 25 MB |
| 動画 | `.mp4` `.webm` `.mov` `.m4v` `.wmv` `.qt` | 200 MB |

> 添付例：**指導案・単元計画**、**教材スライド**、**ワークシート・板書・学習の様子の写真**、**実験や朗読の短い動画**など。

#### マルウェア検査について

運用環境によっては、添付登録直後は**マルウェア検査が完了するまでダウンロードできません**（一覧のサムネイルも検査完了後に表示されます）。検査結果は投稿詳細の添付欄に表示されます。

### 公開と下書き

- 入力後、画面下の「**保存する**」を押すと公開されます。公開後は「**投稿が完了しました**」画面に遷移し、投稿の確認・一覧への戻り・続けて投稿する、が選べます。
- 「**下書きとして保存する**」にチェックを入れると、自分以外には表示されません。保存後は通知が表示され、**マイページ**へ移動します。マイページから後で編集して公開できます。

### ポリシー確認

フォームの最下部に「**投稿前の確認**」のチェック欄があります。**児童生徒の保護**に関わる重要な確認なので、毎回内容を見てチェックしてください。
