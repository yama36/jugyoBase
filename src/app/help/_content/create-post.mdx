<h2 id="create-post">授業実践を投稿する</h2>

ヘッダーの「**新規投稿**」、または事例一覧右上の「**新規投稿**」ボタンから投稿を作成できます。

<HelpMock variant="post-form" />

### 入力項目

必須は <strong className="text-red-600">＊</strong> マークの項目です。

- **タイトル**＊
- **学年**＊：小1〜小6・中1〜中3 などから選択
- **教科**＊：国語・算数・社会・理科・英語 など
- **単元**＊：先に学年・教科を選ぶと、指導要領由来の候補が出てきます。候補にない場合はそのまま入力できます。
- **内容項目**（任意）：単元の中の小トピックや、指導要領上の細目があれば
- **めあて**：児童生徒が「この授業で何ができるようになるか」を一文で
- **振り返り**：児童生徒が「できたこと・難しかったこと・次に頑張ること」
- **工夫した点（POINT）**：先生として工夫したこと
- **簡単な授業の流れ**：導入〜まとめのあらすじ
- **ハッシュタグ**：`#` は不要。スペースまたはカンマ区切り（例：`協同学習 国語 振り返り`）

### 添付ファイル

フォーム上部の「**ファイルを選択**」から添付できます。**保存前から**添付の登録ができ、ファイルの種類はファイル自体から自動判定されます。

| 種類 | 主な拡張子 | サイズ上限 |
| ---- | ---------- | ---------- |
| PDF | `.pdf` | 25 MB |
| スライド（PowerPoint） | `.pptx` `.ppt` | 25 MB |
| 画像 | `.jpg` `.jpeg` `.png` `.webp` `.gif` | 25 MB |
| 動画 | `.mp4` `.webm` `.mov` `.m4v` `.wmv` `.qt` | 200 MB |

> 添付例：**指導案・単元計画**、**教材スライド**、**ワークシート・板書・学習の様子の写真**、**実験や朗読の短い動画**など。

#### マルウェア検査について

運用環境によっては、添付登録直後は**マルウェア検査が完了するまでダウンロードできません**（一覧のサムネイルも検査完了後に表示されます）。検査結果は投稿詳細の添付欄に表示されます。

### 公開と下書き

- 入力後、画面下の「**保存する**」を押すと公開されます。
- 「**下書きとして保存する**」にチェックを入れると、自分以外には表示されません。マイページから後で編集して公開できます。

### ポリシー確認

フォームの最下部に「**投稿前の確認**」のチェック欄があります。**児童生徒の保護**に関わる重要な確認なので、毎回内容を見てチェックしてください。
