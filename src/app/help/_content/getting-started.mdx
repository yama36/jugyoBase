<h2 id="getting-started">はじめての方へ（ログインまで）</h2>

jugyoBase は **Google アカウントでログイン** します。ID・パスワードの登録は不要です。

### 1. 自分の学校を選ぶ

トップページに、登録されている学校（テナント）の一覧が並んでいます。自分の所属する学校をタップしてください。

<HelpMock variant="school-list" />

### 2. Google でログインする

学校のログイン画面で「**Google で続行**」を押し、ふだん職場で使っている Google アカウント（学校のドメインのアカウント）でサインインしてください。

- 学校が **Google ドメイン連携** をしている場合は、そのドメインのアカウントであれば自動的にログインできます。
- 連携していない場合は、**管理者があらかじめ登録したアカウント** のみログインできます。ログインできないときは、校内の管理担当者に登録を依頼してください。

### 3. ナビゲーションの使い方

ログイン後は、ページ上部のヘッダーからすべての機能にアクセスできます。

- **PC・タブレット（横長）**：ヘッダーに「事例一覧・新規投稿・マイページ・教科別一覧・🔔」が横並びで表示されます。
- **スマートフォン（縦画面）**：ヘッダー右上の「**≡ メニューアイコン**」をタップするとナビゲーションメニューが開きます。同じ場所の **✕** をタップすると閉じます。

### 4. プロフィールを整える（任意）

最初に**マイページ → プロフィール編集**から、表示名・役職（例：3年主任）・担当教科・担当学年・自己紹介を入れておくと、コメントや投稿者名がわかりやすくなります。

### 役割について

| 役割 | できること |
| ---- | ---------- |
| 一般 | 投稿・編集・コメント・いいね・ブックマーク・閲覧 |
| 閲覧専用（readonly） | 閲覧・ブックマークのみ。投稿・コメント・いいねはできません |
| 管理者（admin） | 上記すべて + ユーザー管理・統計の閲覧・他人の投稿の編集削除 |

役割の付与・変更は管理者が行います。
