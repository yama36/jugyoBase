<h2 id="overview">jugyoBase とは</h2>

jugyoBase は、**学校（テナント）の中だけで授業・AI活用・業務改善の知見を共有する**ためのクローズドな場です。同じ学校の先生どうしで、実践記録や準備の工夫、AIの活用例を気軽に持ち寄り、校内でのAI活用を日常化することを目的としています。

### 大切にしている考え方

- **校内クローズド**：投稿は同じ学校テナントの先生だけが閲覧できます。他校から見えることはありません。
- **カテゴリで共有しやすい**：投稿時に「授業 / 業務改善 / AI・ICT活用」を選べるため、目的に合った形で知見を残せます。
- **学年・教科・単元で探せる**：授業に関する投稿は、学年・教科・単元で検索しやすい構造になっています。
- **児童生徒の保護を最優先**：顔が判別できる写真や個人を特定できる情報は載せない、という運用を前提にしています。詳しくは「[利用上の注意](#policy)」をご覧ください。

### おもな機能

- 授業 / 業務改善 / AI・ICT活用の投稿・編集・下書き保存
- 参考URLの保存と詳細ページでのリンク表示
- PDF / PowerPoint / 画像 / 動画 の添付（複数種類の一括アップロード、投稿詳細からアプリ内表示）
- 学年・教科・単元・タグ・キーワードでの検索
- **教科別の共有マップ**（教科ごとの投稿状況・今月の増分・共有人数の一覧、および業務改善・AI・ICT活用カテゴリの状況）
- いいね・ブックマーク・コメント
- コメントやいいねの通知
- マイページでの自分の投稿・ブックマーク管理
- 投稿の PDF 保存（印刷ダイアログ）
