<h2 id="overview">jugyoBase とは</h2>

jugyoBase は、**学校（テナント）の中だけで授業実践を共有する**ためのクローズドな場です。同じ学校の先生どうしで、めあて・振り返り・指導案・板書・ワークシートなどを気軽に持ち寄り、お互いの授業づくりに役立てることを目的としています。

<HelpMock variant="post-list" caption="事例一覧（学校テナント内のメイン画面）" />

### 大切にしている考え方

- **校内クローズド**：投稿は同じ学校テナントの先生だけが閲覧できます。他校から見えることはありません。
- **学年・教科・単元で探せる**：誰がいつ書いたかだけでなく、「この単元、誰か実践してたかな」と検索しやすい構造になっています。
- **児童生徒の保護を最優先**：顔が判別できる写真や個人を特定できる情報は載せない、という運用を前提にしています。詳しくは「[利用上の注意](#policy)」をご覧ください。

### おもな機能

- 授業実践の投稿・編集・下書き保存
- PDF / PowerPoint / 画像 / 動画 の添付
- 学年・教科・単元・タグ・キーワードでの検索
- いいね・ブックマーク・コメント
- コメントやいいねの通知
- マイページでの自分の投稿・ブックマーク管理
- 投稿の PDF 保存（印刷ダイアログ）
